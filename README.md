 Sales Analysis Dashboard – Excel

 Project Overview

The Sales Analysis Dashboard is an interactive Excel-based data analysis project designed to analyse sales performance, revenue distribution, customer spending behaviour, and order trends.

This dashboard is developed using Microsoft Excel with PivotTables, PivotCharts, Slicers, and Timeline filters to transform raw sales data into meaningful business insights.

The main objective of this project is to understand sales patterns, identify high-performing product categories, analyse customer behaviour, and monitor overall business performance through interactive visualizations.

 Interactive Dashboard Elements

The dashboard includes interactive filters to make data exploration easier:

- **Gender Slicer:** Filter sales by Male and Female customers.
- **Occasion Slicer:** Analyse sales for Anniversary, Birthday, Diwali, Holi, Raksha Bandhan, Valentine's Day, and other occasions.
- **Order Date Timeline:** Filter sales data by order date.
- **Delivery Date Timeline:** Analyse orders based on delivery dates.

These interactive controls allow users to explore different aspects of sales performance dynamically.
