# Sales & Business Data Analysis Dashboard | Power BI

## Project Overview
This project focuses on analyzing business and sales data using Microsoft Power BI. Three Excel datasets — Orders, Products, and Customers — are used to create an interactive dashboard and answer 10 important business questions.

The main objective is to understand sales performance, customer behavior, product performance, and business trends through interactive visualizations and data analysis.

## Datasets
The project uses three Excel files:

1. **Orders.xlsx** – Contains order details, sales amounts, quantities, and order dates.
2. **Products.xlsx** – Contains product information, product names, categories, and pricing details.
3. **Customers.xlsx** – Contains customer information such as customer IDs, names, and locations.

## Tools & Technologies
- Microsoft Excel – Dataset preparation and storage
- Microsoft Power BI – Data visualization and dashboard creation
- Power Query – Data cleaning and transformation
- DAX – Measures and calculated columns
- Data Modeling – Establishing relationships between datasets

## Business Questions (10 Analysis Tasks)

1. What is the total number of orders?
2. What is the total revenue generated?
3. Which are the top 5 best-selling products?
4. Who are the top 5 customers based on total spending?
5. Which product categories generate the highest sales?
6. Which customers have placed multiple orders?
7. What is the highest-value order?
8. How do sales change month by month?
9. Which products have never been ordered?
10. Which customers contribute the most to total revenue?
